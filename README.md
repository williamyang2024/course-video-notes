# Course Video Notes

Turn course and social videos into structured learning assets.

## Languages

- [English](readme_EN.md)
- [中文](readme_CN.md)

## Quick Start

```powershell
& '.\scripts\run_pipeline.ps1' `
  -Source "https://www.youtube.com/watch?v=VIDEO_ID" `
  -OutDir ".\output\my-course" `
  -Slug "my-course"
```

For full documentation, choose one of the language-specific README files above.
